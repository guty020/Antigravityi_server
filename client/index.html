🖥️ Emparejar Nuevo PC con Antigravity

Conecta tu ordenador o servidor para descubrir repositorios locales, ejecutar tareas de orquestación y monitorear hardware sin abrir puertos en tu router.

CÓDIGO DE ENLACE TEMPORAL Válido por 10 minutos
--- ---
📖 Guía de Emparejamiento Rápido (Noveles & Seniors)
  1. Paso 1: Abre una ventana de terminal en tu ordenador (PowerShell o Símbolo del sistema / CMD). No importa en qué carpeta estés.
  2. Paso 2: Haz clic en el botón "Copiar Comando" de abajo.
  3. Paso 3: Ve a tu terminal, pega el comando con Ctrl + V (o clic derecho) y presiona Enter.
  4. Paso 4: En pantalla verás ¡Emparejado con éxito! y tu PC aparecerá conectado en verde, escaneando proyectos automáticamente.
⚡ Comando Universal (Copia y pega directo en terminal):
curl.exe -s http://localhost:4000/agent.js -o "%TEMP%\agent.js" && node "%TEMP%\agent.js" --server http://localhost:4000 --pair ...
Opciones adicionales según tu consola:
PowerShell:
Invoke-WebRequest -Uri "http://localhost:4000/agent.js" -OutFile "$env:TEMP\agent.js"; node "$env:TEMP\agent.js" --server "http://localhost:4000" --pair ...
Desde la carpeta del proyecto (si estás en MD):
node agent-connector/agent.js --server http://localhost:4000 --pair ...

Supabase Database & Edge Functions POSTGRESQL
SIN TOKEN

¿Qué es? La URL y la clave de acceso (`anon` pública o `service_role` administrativa) de tu proyecto en Supabase.

¿Para qué sirve? Permite a Antigravity ejecutar migraciones SQL, leer esquemas y desplegar Edge Functions.

¿Dónde obtenerlo? Ve a Supabase Dashboard > Project Settings > API > Project API Keys.

▲
Vercel Edge Platform DEPLOYMENTS
SIN TOKEN

¿Qué es? Token personal de acceso (PAT) generado en la plataforma de Vercel.

¿Para qué sirve? Habilita despliegues automáticos desde el orquestador, gestión de dominios y variables de entorno.

¿Dónde obtenerlo? Ve a Vercel Dashboard > Account Settings > Tokens > Create Token.

🔥
Firebase Platform & Firestore CLOUD
SIN TOKEN

¿Qué es? Token de autenticación de Firebase CLI o JSON de clave de cuenta de servicio.

¿Para qué sirve? Permite probar reglas de seguridad, bases de datos Firestore y desplegar Cloud Functions.

¿Dónde obtenerlo? Ejecuta `firebase login:ci` o en Firebase Console > Configuración del proyecto > Cuentas de servicio.

🐙
GitHub Repositories & Sync GIT
SIN TOKEN

¿Qué es? Personal Access Token (PAT) con permisos de lectura y escritura (`repo`, `workflow`).

¿Para qué sirve? Permite al conector hacer commits, sincronizar con la rama remota y crear ramas de respaldo.

¿Dónde obtenerlo? Ve a GitHub > Settings > Developer settings > Personal access tokens > Tokens (classic).
