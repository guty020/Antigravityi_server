# ANTIGRAVITY CONNECTOR — ESTADO DEL PROYECTO

Mantener un archivo `PROJECT_STATE.md` con:

- versión;
- fecha;
- funcionalidades implementadas;
- funcionalidades validadas;
- funcionalidades pendientes;
- limitaciones de APIs externas;
- integraciones conectadas;
- tests ejecutados;
- errores conocidos;
- próximos pasos.

Mantener `CHANGELOG.md`.

Cada cambio importante debe indicar:
- motivo;
- archivos afectados;
- migraciones;
- riesgos;
- tests;
- backup;
- rollback.

No marcar como completado algo que solamente esté programado.
