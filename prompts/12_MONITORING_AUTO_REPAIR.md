- PCs;
- Agent Connector;
- Antigravity;
- proyectos;
- deployments;
- APIs;

## Alertas
- PC offline;
- backup fallido;
- deployment fallido;
- API desconectada;
- certificado próximo a caducar;
- error de base de datos;
- Agent Connector sin heartbeat.

## Auto Repair
Flujo:
```text
DETECT
ANALYZE
BACKUP
PROPOSE
APPROVE IF REQUIRED
EXECUTE
TEST
REPORT
```

Nunca aplicar reparación destructiva sin aprobación.
