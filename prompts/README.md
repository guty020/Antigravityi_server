## Uso
No es necesario pegar todos los archivos en todas las conversaciones.

Usar:
1. Master para establecer reglas.
2. Prompt específico para el módulo que se está trabajando.
3. Testing/Validation antes de cerrar una fase.

El proyecto debe mantenerse como aplicación real, multiusuario, segura y validada.
