# ANTIGRAVITY CONNECTOR — WORKFLOW PARA ANTIGRAVITY

Usa este prompt como regla operativa en cada sesión.

## Antes de modificar
1. Leer README y documentación.
2. Revisar estado Git.
3. Revisar cambios pendientes.
4. Revisar tareas activas.
5. Identificar workspace.
6. Crear backup si procede.
7. Planificar.

## Durante
- cambios pequeños y verificables;
- no sobrescribir trabajo ajeno;
- mantener tipos;
- registrar decisiones;
- ejecutar tests afectados;
- actualizar documentación.

## Después
1. lint
2. typecheck
3. tests
4. build
5. security checks
6. comprobar diff
7. registrar resultado
8. actualizar Project Passport
9. generar informe.

## Regla
Si una prueba no se pudo ejecutar, indicarlo explícitamente. Nunca inventar un resultado.
